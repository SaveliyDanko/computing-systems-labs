# Проверка лабораторной 2

Дата: 07.10.2026. Среда проверки: Linux, ARM GCC 14.2.1, Unicorn 2.x.

## Проверено программно

- HAL-версия и регистровая версия собираются в ELF/BIN.
- Каждая тестовая сборка выполняет 56 C-проверок автомата светофора,
  тайм-аутов, граничных значений парсера, перехода SysTick через ноль и кнопки.
- HAL: 105 интеграционных проверка UART в начальных режимах P и I.
- Собственный драйвер: 101 интеграционная проверок UART в начальных режимах P и I.
- Проверены BRR, AF7, NVIC, эхо, CR/LF/CRLF, режимы кнопки, тайм-аут,
  неверные числа, длинная строка, Backspace, восстановление после FE и RX overflow,
  порядок TX, отказ при полном буфере, сохранение запроса смены режима до TC.
- Дополнительно выполнен запуск обеих готовых прошивок от Reset_Handler:
  проверены вектор USART1, инициализация main и приветствие по UART без fatal.
- Для HAL дополнительно проверены конечный TX timeout и отсутствие повторной
  отправки байта, уже записанного в DR перед тайм-аутом.
- Перенесённая ЛР 1 собрана; прежние 85 C-проверок GPIO/кнопки/светофора проходят.

Отчёт текущего запуска сохраняется в `build/test-results.txt`.
MMIO-модель не воспроизводит физическое время, USB и вытеснение main прерыванием
в каждой возможной точке; она вызывает реальный USART1 ISR на границах шагов.

## Осталось проверить на стенде

1. Доступ через OpenOCD/JTAG и прошивку обеих версий.
2. COM-порт Interface 1, скорость 57600 8N1, эхо и ответы терминалу.
3. Цвета, кнопку и интервалы на реальных светодиодах, без остановки отладчика.
4. Последовательно `?`, `set mode 2`, `set mode 1`, `set timeout 8`,
   `set interrupts off`, `?`, `set interrupts on`, `?`.
5. Убедиться, что I/P переключаются и светофор продолжает работать во время обмена.

Реальное выполнение на оборудовании не подтверждено. До этой проверки работа
имеет подтверждённую сборку и программную валидацию.
