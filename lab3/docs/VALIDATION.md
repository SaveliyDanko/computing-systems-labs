# Проверка лабораторной 3

Дата: **02.11.2026**. Среда: Linux, ARM GCC 14.2.1, Python 3.14,
Unicorn 2.1.4, pyelftools 0.33.

## Результат

Production и тестовая сборки Cortex-M4 проходят. Последний запуск:

```text
PASS: 370 Cortex-M4 C assertions; 313 timer/UART/boot checks
```

Протокол каждого запуска записывается в `build/test-results.txt`.
Production `arm-none-eabi-size`: text 15888, data 100, bss 2684 байта.
При компоновке с `nosys.specs` возможны сообщения newlib о `_read`/`_write`/
`_close`/`_lseek`: обмен приложения выполняется через `serial`, стандартные
потоки не используются. Собственный C компилируется с `-Wall -Wextra -Werror`.

Проверено:

- Все 63 частоты по независимой формуле равномерной темперации, их порядок
  и удвоение при переходе между октавами.
- Начальные значения, клавиши, границы октав и длительности, неверный ввод.
- Одна нота и гамма, точные границы длительности, позднее обновление,
  переполнение `uint32_t`, снимок настроек и замена текущего воспроизведения.
- CR, LF и CRLF; один запуск на CRLF, отдельные сообщения нот гаммы без дублей.
- PA5/AF1, PWM1, ARR/CCR/PSC, 32-разрядный период низкой ноты, около 50 % duty,
  загрузка параметров и остановка CCR=0/CEN=0.
- PLL, SYSCLK/HCLK 120 МГц, APB1 30 МГц, APB2 60 МГц, Flash latency,
  SysTick 1 мс, BRR=1042 при 57600 бод; запуск после иной активной PLL.
- Настоящий HAL UART и ISR: немедленная реакция на отдельный символ,
  эхо, ответы, ошибки RX, переполнение и восстановление без ожидания Enter.
- Готовая прошивка от Reset_Handler: вектор USART1, запуск main без fatal,
  приветствие, команда ноты, запуск PWM и остановка по длительности.

Исходные ЛР 1 и 2 также проверены в отдельной временной копии: ЛР 1 — 85
C-проверок; ЛР 2 HAL — 56 C + 105 интеграционных; ЛР 2 register — 56 C + 101
интеграционная. Все сборки и тесты прошли.

## Границы программной проверки

Unicorn выполняет скомпилированный C, включая реальные UART HAL-функции.
MMIO-модель воспроизводит RCC ready/status, битовые операции, UART RXNE/TXE/TC,
ошибки, NVIC и GPIO BSRR. Проверяются регистры TIM2; физических PWM-фронтов,
аналогового тракта, USB/FT2232 и звучания в модели нет. USART1 ISR вызывается
между шагами приложения, без моделирования всех возможных моментов вытеснения.

## Сценарий на стенде

1. Замкнуть SA2.7, подключить питание и DBG USB, прошить `build/lab3.elf`.
2. Открыть Interface 1: 57600 8N1, UTF-8, local echo и line editing выключены.
3. Проверить приветствие, начальные 5/9 и 1,0 с; нажать `6` без Enter — Ля 440 Гц.
4. Сыграть `1`–`7`, проверить сообщения и завершение каждой ноты.
5. Проверить `+`, `-`, `A`, `a`, крайние значения и `LIMIT` за границами.
6. Enter — семь нот без заданных пауз; поменять настройки во время гаммы,
   затем заменить её отдельной нотой.
7. Проверить ошибочный `x`: сообщение «неверный символ», код 0x78;
   следующая правильная клавиша сразу работает.
8. При наличии осциллографа измерить PA5 для 440 Гц и крайних октав,
   проверить длительность без остановок отладчика и низкий уровень после ноты.

**Физическое выполнение на оборудовании пока не подтверждено.**
